> benchmarks, method, source, rapira.

Each chart shows the change of the new build of each run from one fixed baseline build: the new build of the first run on the chart. Every run measures its new build and its base build one after the other on the same instances. When the base build is the baseline build, the point is the median of the paired deltas of the run, and it does not include the difference between two rigs. A run with another base build compares its new median with the new median of the first run on the chart, so its point includes the difference between two rigs. The measures are capacity in req/s, and p99 latency and RSS at a constant request rate per target. A higher capacity is better. A lower p99 and a lower RSS are better. A paired point is green for a better build and red for a worse build only when every round gave a pair, all the paired deltas are on one side of zero, and the delta reaches the noise floor. The noise floor is the largest paired delta of a run in which the two builds are the same build. The gRPC p99 has a higher noise floor. Other points are gray, and a point between two rigs is always gray. A gap means a measurement is missing. The tooltip includes the measured values of the two builds of the run, and the smallest and the largest paired delta. A click opens the pull request, or the commit for a run without one. On a touch screen, a tap shows the tooltip, and a tap on a point opens the run.
